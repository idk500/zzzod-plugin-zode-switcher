# ZODE 切换器

绝区零一条龙第三方插件：一键将代码源切换到 idk500 增强源（CNB，ZODE 分支），无需手动编辑配置文件。

## 使用

1. 将本仓库 Release 的 zip 导入主程序「资源管理 → 插件管理」，或解压到主程序 `plugins/zode_switcher/`；
2. 重启后运行工具列表中的「ZODE 切换器」；
3. 按提示重启一条龙，之后自动从增强源更新代码。

已是增强源时运行会直接提示无需重复切换；想回官方版在「资源管理」切回即可。

## 声明

仅修改 `config/repository.yml`（代码源声明）与 `config/env_config.yml`（用户选择），不进行任何游戏画面操作。
